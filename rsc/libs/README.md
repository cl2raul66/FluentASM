# `rsc/libs/` — Bibliotecas nativas

Aquí van los ficheros `.bin`: fragmentos de código máquina ya compilado que FluentASM incrusta dentro
de la imagen final (Fase 4 del [roadmap](../../roadmap.md)).

- **Sí se versionan**: son recursos de origen, no resultados de compilación.
- Por eso `.gitignore` **no** ignora `*.bin`, aunque sí las imágenes generadas (`.x64`, `.x86`, `.arm`).

Carpeta vacía por ahora: la funcionalidad llega en la Fase 4.
